# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using an e-commerce dataset. The analysis focuses on understanding customer demographics, purchasing patterns, spending behavior, category preferences, purchase frequency, discount usage, subscription status, and payment and shipping preferences.

The project uses Python-based exploratory data analysis and visualization to identify meaningful patterns and relationships in customer behavior.

## Dataset

The dataset contains customer-level shopping information, including:

* Customer demographics such as age, gender, location, and age group
* Purchased items and product categories
* Purchase amount
* Season and color
* Review rating
* Subscription status
* Shipping type
* Discount applied
* Previous purchases
* Payment method
* Purchase frequency

## Objectives

* Understand the overall customer profile and demographics.
* Analyze customer purchasing and spending patterns.
* Identify popular products and categories.
* Study purchase frequency and previous purchase behavior.
* Compare shopping behavior based on subscription and discount usage.
* Analyze customer preferences for payment and shipping methods.
* Explore relationships between customer characteristics and purchase behavior.

## Analysis

The project follows the following analytical process:

1. Load the dataset using Python.
2. Clean and prepare the data for analysis.
3. Handle missing values and data inconsistencies.
4. Perform feature engineering to create useful analytical features.
5. Conduct Exploratory Data Analysis (EDA).
6. Analyze customer behavior using statistical summaries and visualizations.
7. Identify meaningful trends and patterns from the results.

## Visualizations

The project uses **Matplotlib, Seaborn, and Plotly** to analyze and visualize customer behavior.

Key visualizations include:

* Customer distribution by gender and age group
* Age and purchase amount distributions
* Category-wise purchase analysis
* Purchase amount by category and customer segment
* Seasonal shopping behavior
* Discount and subscription behavior
* Purchase frequency analysis
* Previous purchases vs. purchase amount
* Review rating analysis
* Payment and shipping preferences
* Correlation heatmap
* Interactive Plotly visualizations

## Insights

The analysis is used to identify patterns in customer spending, product preferences, purchase frequency, subscription behavior, discount usage, and other shopping characteristics.

The final insights are derived from the visualizations and EDA results and can be used to better understand customer behavior and support data-driven business decisions.

1. Clone or download the project.
2. Open the Jupyter Notebook.
3. Place the dataset in the appropriate project folder.
4. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn plotly
```

5. Run the notebook cells sequentially to reproduce the analysis and visualizations.
